## 未发布性能优化：八套主题

验证日期：2026-10-30。基准为改动前的运行包（提交 `1e38068`）。本轮在提交前重新检查最终源码与根目录 `client.js`；尚未发布新版本标签，也没有重新安装或验收真实 dsh 宿主。

### 优化范围

- 浮云、海龟、锦鲤、水母、萤火和月色复用固定背景，避免每帧重复绘制渐变与固定网格。缓存保持原画布分辨率；非整数采样导致边缘不足一个完整像素时，保留原绘制方式，避免改变边缘叠色。
- 锦鲤复用鱼身格子对象，提前计算同一帧不变的鱼鳍参数与固定水面字符。无水波时跳过逐格扫描；有水波时只计算波形实际可能传播到的区域，保留原方程、反光和衰减。
- 水母预计算固定粒子和触须参数，减少颜色计算中的数组分配；海龟先排除鳍肢轮廓之外的采样点；萤火缓存草丛配色并减少重复字体设置。
- 纸船缓存渐变和无水波时的完整绘制路径，保留原有逐帧叠色；一次性的网格构建放在独立函数中。尺寸变化与卸载时主动释放旧船体位图。
- 暖夜保留原主画布算法，小蟹只在姿势或位置改变时更新画布和 DOM。会话正文的普通输出不再触发全局布局扫描；按钮等控件的新增、删除和文字变化，以及宿主结构变化，仍会检查布局。
- 锦鲤背景点击首次立即响应，随后每 500 ms 最多接受一次；超出的点击直接忽略，不排队。其他主题没有新增点击间隔限制。

没有降低目标刷新频率、字符密度或采样清晰度，也没有改变动物运动、配色和水波造型。

### 提交前性能复测

隔离 Edge 156.0.4314.42，1920×1080、设备像素比 1。同一浏览器中每种场景按“旧、新、新、旧”交替运行，每次预热 700 ms、采样 2 秒。共 20 种条件、80 次采样；性能采样与其他浏览器测试顺序执行。下表是两次采样的单帧绘制耗时中位数均值，包含 Canvas 绘制调用，**不是整机 CPU 使用率或 GPU 总耗时**。

| 场景 | 优化前（ms） | 优化后（ms） | 单帧耗时变化 |
| --- | ---: | ---: | --- |
| 暖夜 | 3.15 | 3.35 | 主画布算法不变 |
| 浮云 | 2.20 | 2.15 | 下降 2% |
| 海龟 | 3.75 | 3.30 | 下降 12% |

| 萤火 | 4.25 | 2.90 | 下降 32% |
| 月色 | 2.65 | 2.90 | 升高 9% |

暖夜主画布保持原实现，不将短时测量差异算作太阳渲染的优化收益；小蟹与宿主扫描优化不在这个独立主画布耗时中。数据存在短时波动，本文保留升高或帧率回退的样本，不承诺每项测量都更快。

### 内存与生命周期

固定背景缓存以额外一张同分辨率位图换取重复绘制的减少。1920×1080 / 1 倍像素比时，启用缓存的场景新增位图原始像素约 **7.9 MiB**；这是位图大小估算，不是进程总内存。高 DPI 下随实际画布像素数增加。静态缩略图不创建该缓存；新增缓存在暂停、隐藏、移出可见区域、减少动态效果、尺寸变化、换景或卸载时释放。暖夜原有底图和纸船自身位图仍遵循各自生命周期。

`tests/performance-resources.mjs` 在真实 Canvas 中控制时钟与观察器通知，验证了：

- 八套渲染器各只有一个动画循环，连续帧复用已有位图，静态画面冻结。
- 960×720 / 2 倍像素比下缓存按预期创建；缩放到 640×480 后旧位图缩为 1×1，并重建对应尺寸资源。
- 移出可见区域、页面隐藏及减少动态效果时没有持续动画循环；新增背景缓存清空。
- 静态预览不创建新增背景缓存；卸载后背景与纸船位图缩为 1×1，监听器和观察器清理。
- 非整数像素边界回退到原绘制方式，恢复完整像素边界后重新缓存。
- 锦鲤首次响应、同一时刻 100 次连点拒绝、499/500 ms 边界及控件隔离均通过。
