压力检查的过渡动画最大并发为 1，结束后为 0；没有页面异常或崩溃。采样的 DOM 节点和事件监听器数量保持稳定。暖夜 1920×1080 渲染检查约为 60 FPS，该结果仅代表测试机器，不能作为所有设备的性能承诺。

审查中复现并修复了「禁用插件后保留场景的明暗模式」的问题，新增回归断言确认恢复原有浅色偏好。

## 演示与发布范围

`demo/` 提供独立宿主模拟页面，使用真实渲染器与虚构会话标题。`docs/media/` 中的截图与 GIF 均由这些页面生成。它们用于展示场景和选择器，不是 dsh 实机聊天截图。

发布包仅包含服务端空入口、浏览器构建产物、Bundle patch、图标、语言文件、介绍及许可证。源码、可复现测试与演示留在 GitHub 仓库；本地验收笔记、历史截图、临时数据、依赖目录和电脑路径不发布。

## 真实宿主加载

另使用 dsh 0.2.1-rc.3 的官方 CLI，在独立 DSH_HOME、空白 web profile 中安装打包产物。安装成功；Edge 中主题入口、八套主题、原生恢复和插件管理页的名称、简介与图标均正常。通过宿主插件开关禁用后，背景和入口移除，配色恢复为原先的浅色。

测试未配置模型或发送消息，未使用现有 profile 的聊天与配置。该检查覆盖真实 Web 宿主加载，不等同于所有桌面壳、操作系统或后续版本的完整验收。宿主更改主题接口、插槽或布局标记后，需要重新验证兼容性。
